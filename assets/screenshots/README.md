# Screenshots de proyectos

Coloca aquí las capturas de pantalla de cada proyecto.

## Especificaciones recomendadas

- **Tamaño:** 1200 × 630 px (ratio 2:1 — mismo que og:image)
- **Formato:** PNG o JPG
- **Nombre:** igual que el repo, en minúsculas con guiones (ej. `amipattern.png`)

## Cómo tomar un buen screenshot

### Opción 1 — Desde el navegador
1. Abre el proyecto en Chrome
2. DevTools → Ctrl+Shift+P → "Capture screenshot" o "Capture full size screenshot"
3. Recorta a 1200×630 con cualquier editor

### Opción 2 — Sin abrir Issues
Arrastra la imagen directamente al textarea de un Issue en GitHub
y copia la URL generada (`https://user-images.githubusercontent.com/...`).
Úsala como `src` en el `<img>` del portafolio — no necesitas guardar el archivo.
